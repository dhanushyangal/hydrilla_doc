# Edit Image

Refines an existing image prior to 3D generation. Ideal for adding armor parts, tweaking colors, or adjusting textures.

### Request Body (JSON or Multipart)

<ParamField body="image_url" type="string">
  URL of the image to edit (or supply file via multipart `image`).
</ParamField>

<ParamField body="prompt" type="string" required>
  Instruction describing the modification (e.g. "Add glowing blue runes").
</ParamField>

<ParamField body="model" type="string" default="openai">
  Model provider: `openai` or `gemini`.
</ParamField>

<ParamField body="quality" type="string" default="low">
  Quality tier: `low` or `high`.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://api.hydrilla.ai/v1/images/edit \
  -H "Authorization: Bearer hyd_live_your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "image_url": "https://assets.hydrilla.ai/character.png",
    "prompt": "Make the armor weathered with moss and battle scratches",
    "model": "openai",
    "quality": "high"
  }'
```
</RequestExample>
