# Developer Profile & Quota

Returns the developer workspace details, current plan, and total vs remaining credit balance.

<RequestExample>
```bash cURL
curl https://api.hydrilla.ai/v1/user/me \
  -H "Authorization: Bearer hyd_live_your_api_key_here"
```
</RequestExample>

### Response

```json
{
  "object": "user",
  "id": "user_2a3b4c",
  "plan": "studio",
  "credits": {
    "total": 1000,
    "used": 42,
    "remaining": 958
  },
  "active_key": {
    "id": "key_892b1",
    "name": "Production Server"
  }
}
```
