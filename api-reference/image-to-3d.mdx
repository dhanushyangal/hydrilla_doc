# Image to 3D Generation

Submits an image directly into the BlueFox 3D cascade pipeline. This endpoint supports both JSON with an image URL or multipart file upload.

### Request Body (JSON)

<ParamField body="image_url" type="string" required>
  Publicly accessible URL of the image to reconstruct.
</ParamField>

<ParamField body="resolution" type="integer" default="1536">
  Target cascade resolution. Supported values: `1024`, `1536`.
</ParamField>

<ParamField body="seed" type="integer" default="42">
  Random seed for reproducible latent synthesis.
</ParamField>

### Response

<ResponseField name="id" type="string">
  Unique task ID to poll for status.
</ResponseField>

<ResponseField name="status" type="string">
  Task state (`PENDING` or `IN_PROGRESS`).
</ResponseField>

<ResponseField name="resolution" type="integer">
  Reconstruction resolution.
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST https://api.hydrilla.ai/v1/3d/image-to-3d \
  -H "Authorization: Bearer hyd_live_your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "image_url": "https://assets.hydrilla.ai/sample-prop.png",
    "resolution": 1536,
    "seed": 42
  }'
```

```python Python
import requests

res = requests.post(
    "https://api.hydrilla.ai/v1/3d/image-to-3d",
    headers={"Authorization": "Bearer hyd_live_your_api_key_here"},
    json={
        "image_url": "https://assets.hydrilla.ai/sample-prop.png",
        "resolution": 1536
    }
)
print(res.json())
```
</RequestExample>
