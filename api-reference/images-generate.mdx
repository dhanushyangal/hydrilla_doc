# Generate Image

Produces an orthographically centered concept image optimized for subsequent 3D modeling.

### Request Body (JSON)

<ParamField body="prompt" type="string" required>
  Description of the object or asset.
</ParamField>

<ParamField body="model" type="string" default="openai">
  Model provider: `openai` or `gemini`.
</ParamField>

<ParamField body="quality" type="string" default="low">
  Quality tier: `low` (fast draft) or `high` (production resolution).
</ParamField>

<ParamField body="aspect" type="string" default="1:1">
  Aspect ratio: `1:1`, `3:2`, or `2:3`.
</ParamField>

<RequestExample>
```bash cURL
curl -X POST https://api.hydrilla.ai/v1/images/generate \
  -H "Authorization: Bearer hyd_live_your_api_key_here" \
  -H "Content-Type: application/json" \
  -d '{
    "prompt": "Ornate golden chalice with sapphire gems, isolated on solid white background",
    "model": "openai",
    "quality": "high",
    "aspect": "1:1"
  }'
```
</RequestExample>
